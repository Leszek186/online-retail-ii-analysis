# Online Retail II: sales analysis in SQL, Excel/Power Query and Python

Work in progress. I am analysing two years of transactions from a UK online gift-ware retailer ([UCI Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii)).

## Questions
1. How concentrated is the revenue across products and customers?
2. When are the strong and weak periods?
3. Which customers are worth protecting and which are slipping away?

## Plan
- [ ] Load the data into a SQL database
- [ ] Clean the data in SQL
- [ ] Net revenue, concentration, seasonality, RFM in SQL
- [ ] Repeat the key steps in Excel / Power Query
- [ ] Cross-check the results in Python
